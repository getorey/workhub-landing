태스크 ​

토픽 내에서 태스크를 생성하고 관리합니다. 칸반 보드와 간트 차트 두 가지 뷰를 제공합니다.

태스크 보기 ​

토픽 상세 화면 > 태스크 탭을 선택합니다. 상단의 토글로 뷰를 전환합니다:

  • 보드: 칸반 스타일 (할 일 → 진행중 → 검토 → 완료)
  • 간트차트: 타임라인 기반 일정 뷰

태스크 생성 ​

보드에서 생성 ​

  1. 원하는 상태 컬럼의 "+" 버튼을 클릭합니다.
  2. 제목, 설명, 우선순위, 담당자, 마감일을 입력합니다.

메시지에서 생성 ​

메시지 액션 메뉴 > **"태스크 만들기"**를 클릭하면 메시지 내용이 태스크 설명에 자동 입력됩니다.

캘린더에서 빠른 생성 ​

나의 태스크 > 캘린더 뷰에서 날짜 셀을 클릭하면 빠른 생성 팝오버가 표시됩니다. 제목과 프로젝트/토픽을 선택하여 즉시 태스크를 생성할 수 있습니다.

태스크 상태 ​

상태설명
할 일 (todo)아직 시작하지 않은 태스크
진행중 (in_progress)현재 작업 중
검토 (review)검토 대기 중
완료 (done)완료된 태스크

보통파랑

작업일지 (Work Log) ​

태스크에 실제 작업 시간을 기록합니다. 계획 대비 실적을 추적하여 프로젝트 진행 현황을 파악할 수 있습니다.

작업일지 작성 ​

  1. 태스크 상세 또는 나의 태스크 > 작업일지 탭에서 **"+ 작업일지 추가"**를 클릭합니다.
  2. 작업 날짜, 시작 시간, 종료 시간을 입력합니다.
  3. 작업 내용(메모)을 입력합니다.
  4. 시간은 자동으로 계산됩니다 (예: 09:00~18:00 = 8시간).

초과근무 표시 ​

표준 근무시간을 초과하는 작업은 자동으로 초과근무로 표시됩니다.

간트 차트에서 작업일지 시각화 ​

간트 차트에서 태스크 바 위에 실제 작업일지가 블록으로 표시됩니다:

  • 계획 기간: 태스크의 시작일~마감일 (바 전체)
  • 실제 작업: 작업일지 블록이 시간대별로 오버레이
  • 시간 단위 줌 레벨에서 시작/종료 시간까지 상세하게 표시됩니다.

간트 차트 ​

타임라인 뷰 ​

  • 시간별 / 일별 / 주별 / 월별 줌 레벨을 전환할 수 있습니다.
  • 오늘 날짜는 빨간 점선으로 표시됩니다.
  • 오늘로 이동 버튼으로 현재 날짜 위치로 스크롤합니다.
  • 줌 레벨 변경 시 자동으로 오늘 위치로 스크롤됩니다.
  • 시간별 뷰는 오늘 ±7일 범위로 제한되고, 진입 시 오늘 12시를 중앙에 표시합니다.

태스크 바 드래그 ​

  • 좌우 드래그: 태스크의 시작일/종료일을 변경합니다.
  • 좌우 끝 드래그: 시작일 또는 종료일만 개별 변경합니다.

순서 변경 ​

좌측 태스크 목록에서 드래그 핸들을 잡고 위아래로 드래그하면 순서가 변경됩니다. 변경된 순서는 서버에 자동 저장됩니다.

태스크 편집 ​

태스크 이름을 클릭하면 편집 팝오버가 열립니다:

  • 제목, 설명, 상태, 우선순위, 날짜 수정
  • 마일스톤 설정
  • 의존성 관리: 선행 태스크를 추가/삭제할 수 있습니다.

의존성 (선행 태스크) ​

태스크 간의 선후 관계를 설정하면 간트 차트에 화살표로 표시됩니다.

  1. 태스크 편집에서 의존성 섹션의 "추가" 버튼을 클릭합니다.
  2. 선행 태스크를 선택합니다.
  3. 삭제하려면 의존성 목록의 휴지통 아이콘을 클릭합니다.

리소스 간트 (자원 관리) ​

프로젝트 멤버별 작업 현황을 리소스 간트 차트로 확인할 수 있습니다:

  • 멤버별 배정된 태스크 바 표시
  • 작업일지 블록 오버레이로 계획 대비 실적 비교
  • 계획 공수(man-day) 대비 실제 투입 시간 리포트

나의 태스크 ​

사이드바 > 나의 태스크를 클릭하면 나에게 배정된 전체 태스크를 확인할 수 있습니다.

요약 통계 ​

상단에 현재 태스크 현황이 표시됩니다:

  • 할 일 / 진행중 / 검토 / 완료 / 지연 건수

날짜 프리셋 칩 ​

요약 카드 아래에 빠른 날짜 필터 칩이 있습니다:

  • 전체 / 오늘 / 이번 주 / 이번 달 / 지연 / 마감임박(7일)
  • 칩 클릭 한 번으로 마감일 기준 필터링

표시 옵션 ​

필터 영역 우측에 두 개의 체크박스:

  • 완료 숨김 (기본 ON) — 완료된 태스크를 목록에서 숨깁니다.
  • 프로젝트별 그룹 (기본 ON) — 태스크를 프로젝트별 헤더로 묶어 표시합니다. 끄면 하나의 평면 목록이 됩니다.

표시 옵션은 브라우저에 저장되어 다음 접속 시에도 유지됩니다.

필터 ​

  • 검색 — 태스크 제목으로 검색
  • 우선순위 — 긴급/높음/보통/낮음
  • 프로젝트 — 특정 프로젝트의 태스크만
  • 토픽 — 프로젝트의 세부 토픽. 드롭다운 내에서 진행중 → 완료 순으로 자동 그룹화

테이블 정렬 ​

테이블 뷰에서 컬럼 헤더(태스크명/상태/우선순위/마감일)를 클릭하면 해당 기준으로 정렬됩니다. 같은 헤더를 다시 클릭하면 오름차순/내림차순이 전환되며, 정렬 상태는 브라우저에 저장됩니다.

뷰 모드 ​

세 가지 뷰 모드를 전환할 수 있습니다:

  • 테이블 뷰: 태스크 목록을 테이블 형태로 표시. 컬럼 헤더 클릭으로 정렬 가능.
  • 간트 차트 뷰: 나에게 배정된 태스크를 타임라인에 표시. 시간별 뷰는 오늘 ±7일로 제한.
  • 캘린더 뷰: 월별 캘린더에 마감일 기준으로 태스크 표시. 날짜 클릭으로 빠른 태스크 생성 가능.

인라인 편집 ​

테이블 뷰에서 상태, 우선순위, 마감일을 클릭하여 즉시 변경할 수 있습니다.
