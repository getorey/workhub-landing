목차

프로젝트 ​

프로젝트는 Workhub의 핵심 업무 단위입니다. 프로젝트 안에 토픽(주제별 논의)을 만들고, 각 토픽에서 메시지와 태스크를 관리합니다.

프로젝트 목록 ​

사이드바 > 프로젝트를 클릭하면 참여 중인 프로젝트 목록이 표시됩니다.

프로젝트 그룹 ​

프로젝트를 그룹으로 분류하여 관리할 수 있습니다:

  1. 프로젝트 목록에서 "+ 그룹 만들기" 버튼을 클릭합니다.
  2. 그룹 이름을 입력합니다.
  3. 프로젝트를 그룹에 포함시키거나 이동할 수 있습니다.
  4. 그룹 공개 설정: 관리자만 보기 또는 전체 공개를 선택할 수 있습니다.

프로젝트 생성 ​

  1. 프로젝트 목록 화면에서 "+ 프로젝트 만들기" 버튼을 클릭합니다.
  2. 프로젝트 이름과 설명을 입력합니다.
  3. 토픽 정책을 선택합니다:
    • 필수: 모든 메시지가 토픽 단위로 관리됩니다.
    • 선택: 토픽 없이도 사용 가능합니다.

프로젝트 상세 ​

프로젝트를 클릭하면 다음 정보를 확인할 수 있습니다:

  • 토픽 목록: 프로젝트 내 토픽들
  • 구성원: 프로젝트 참여자 목록
  • 프로젝트 설정: 이름, 설명 수정

토픽 ​

토픽은 프로젝트 내의 주제별 논의 공간입니다.

토픽 생성 ​

  1. 프로젝트 상세 화면에서 "+ 토픽 만들기" 버튼을 클릭합니다.
  2. 토픽 이름과 설명을 입력합니다.

토픽 상태 ​

상태설명
진행중현재 활동 중인 토픽
완료목적을 달성한 토픽
보관더 이상 사용하지 않는 토픽

토픽 상세 ​

토픽을 클릭하면 두 개의 탭이 표시됩니다:

  • 메시지 탭: 토픽 내 대화, 쓰레드, 리액션
  • 태스크 탭: 칸반 보드 또는 간트 차트 뷰

프로젝트 구성원 ​

역할 ​

역할권한
admin프로젝트 설정, 구성원 관리, 보관
member토픽 생성, 메시지, 태스크
guest읽기 전용

구성원 초대 ​

프로젝트 관리자(admin)가 프로젝트 상세 > 구성원 섹션에서 사용자를 초대합니다.

토픽 이동 / 병합 ​

기관 관리자 또는 프로젝트 관리자는 토픽을 다른 프로젝트로 이동하거나 다른 토픽과 병합할 수 있습니다.

토픽 이동 ​

  1. 토픽 설정 메뉴에서 **"토픽 이동"**을 선택합니다.
  2. 이동할 대상 프로젝트를 선택합니다.
  3. 이동 전 미리보기에서 영향받는 태스크와 의존성을 확인합니다.
  4. 다른 프로젝트의 태스크와 의존성이 있는 경우 경고가 표시됩니다.

토픽 병합 ​

  1. 토픽 설정 메뉴에서 **"토픽 병합"**을 선택합니다.
  2. 병합 대상 토픽을 선택합니다.
  3. 원본 토픽의 메시지와 태스크가 대상 토픽으로 합쳐집니다.

프로젝트 보관 / 삭제 ​

보관 ​

프로젝트를 보관하면 읽기 전용 상태가 됩니다. 메시지와 태스크를 조회할 수 있지만 새로운 작성은 불가합니다.

삭제 ​

프로젝트 삭제 전 영향받는 토픽, 태스크, 메시지, 파일 수가 표시됩니다. 확인을 위해 프로젝트 이름을 직접 입력해야 합니다. 삭제된 프로젝트는 기관 관리자의 보관함에서 확인할 수 있습니다.

삭제 권한:

  • 프로젝트 개설자(owner)
  • 기관 관리자(org_admin) / 시스템 관리자(system_admin)

토픽 삭제 ​

프로젝트 상세 화면의 토픽 목록에서 각 토픽 항목에 마우스를 올리면 휴지통 아이콘이 나타납니다.

  1. 휴지통 아이콘을 클릭합니다.
  2. 영향받는 태스크 수와 메시지 수가 표시됩니다.
  3. 확인을 위해 토픽 이름을 직접 입력합니다.
  4. "영구 삭제" 버튼을 클릭합니다.

삭제 권한:

  • 토픽 생성자
  • 프로젝트 개설자
  • 기관 관리자(org_admin) / 시스템 관리자(system_admin)

일반 멤버는 휴지통 아이콘이 표시되지 않아 삭제 버튼을 볼 수 없습니다.
