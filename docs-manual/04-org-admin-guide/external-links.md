# 외부 링크 관리

사이드바에 외부 웹 서비스 링크를 추가하여 사용자가 빠르게 외부 서비스에 접근할 수 있도록 합니다. SSO 연동과 함께 사용하면 로그인 없이 외부 서비스로 이동할 수 있습니다.

## 외부 링크 추가

1. 관리자 메뉴 > **외부 링크 관리**로 이동합니다.
2. **"+ 링크 추가"** 버튼을 클릭합니다.
3. 다음 정보를 입력합니다:

| 항목 | 설명 |
|------|------|
| 이름 | 사이드바에 표시되는 링크 이름 |
| URL | 외부 서비스 URL |
| 열기 방식 | iframe(앱 내 표시) 또는 새 탭 |
| SSO 연동 | SSO 설정이 있으면 자동 로그인 연동 가능 |

## 열기 방식

- **iframe**: Workhub 앱 내에서 외부 서비스를 표시합니다. 일부 사이트는 iframe을 차단할 수 있으며, 이 경우 자동으로 감지하여 안내합니다.
- **새 탭**: 새 브라우저 탭에서 외부 서비스를 엽니다.

## 순서 변경

링크 목록에서 드래그하여 표시 순서를 변경할 수 있습니다. 변경된 순서는 사이드바에 즉시 반영됩니다.

## SSO 연동

외부 링크에 SSO 설정을 연결하면, 사용자가 링크를 클릭할 때 SSO를 통해 자동으로 로그인된 상태로 외부 서비스에 접근합니다.

1. 외부 링크 편집에서 **SSO 연동** 옵션을 선택합니다.
2. 등록된 SSO 설정 중 연동할 서비스를 선택합니다.
3. 사용자가 링크를 클릭하면 SSO 인증 후 외부 서비스로 이동합니다.
