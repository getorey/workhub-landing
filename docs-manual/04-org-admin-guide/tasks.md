# 태스크 관리 (기관 관리자)

기관 전체의 태스크 현황을 확인하고, 업무 부하를 모니터링합니다.

## 태스크 관리 접근

관리자 메뉴 > **태스크 관리**로 이동합니다.

## 기관 전체 태스크 조회

모든 프로젝트/토픽의 태스크를 한 화면에서 조회할 수 있습니다.

### 필터

다양한 조건으로 태스크를 필터링할 수 있습니다:

| 필터 | 설명 |
|------|------|
| 담당자 | 특정 사용자에게 배정된 태스크 |
| 부서 | 특정 부서 멤버의 태스크 |
| 프로젝트 | 특정 프로젝트의 태스크 |
| 상태 | 할 일, 진행중, 검토, 완료 |
| 기간 | 시작일/마감일 범위 |

## 업무 부하 리포트

담당자별 업무 현황을 한눈에 파악할 수 있습니다:

| 항목 | 설명 |
|------|------|
| 진행중 | 현재 작업 중인 태스크 수 |
| 지연 | 마감일이 지난 미완료 태스크 수 |
| 완료 | 완료된 태스크 수 |
| 전체 | 배정된 전체 태스크 수 |

업무 부하가 높은 담당자를 파악하여 업무를 재분배하는 데 활용할 수 있습니다.
