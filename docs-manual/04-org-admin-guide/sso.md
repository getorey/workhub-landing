# SSO 연동 설정

외부 서비스(하이웍스 등)와 SSO(Single Sign-On)를 설정하여, 기관 사용자가 Workhub에서 외부 서비스로 로그인 없이 이동할 수 있습니다.

## SSO 설정 추가

1. 관리자 메뉴 > **SSO 연동 설정**으로 이동합니다.
2. **"SSO 설정 추가"** 버튼을 클릭합니다.
3. 다음 정보를 입력합니다:

| 항목 | 설명 | 예시 |
|------|------|------|
| 서비스 | SSO 프로바이더 선택 | 하이웍스 (Hiworks) |
| 표시명 | 사용자에게 표시되는 이름 | 하이웍스 |
| API Key | 외부 서비스에서 발급받은 API Key | cf37c94b... |
| 오피스 도메인 | 외부 서비스 오피스 도메인 | dohwa.pro |
| 오피스 고유번호 | 하이웍스 오피스관리 > 회사정보에서 확인 | 606410 |
| 공용 로그인 ID | (선택) 모든 유저가 공유할 하이웍스 아이디 | kjw |

4. **"등록"** 버튼을 클릭합니다.

## 하이웍스 SSO 설정 방법

### 사전 준비 (하이웍스 관리자 콘솔)

1. 하이웍스 오피스관리 > 서비스 연동(API) > **SSO 관리**로 이동합니다.
2. **내부로 연동** 탭 > **"+ 내부로 연동 추가"**를 클릭합니다.
3. API Key를 발급받습니다.
4. **연동 서버 IP**에 Workhub 서버의 IP 주소를 등록합니다.

### Workhub에서 설정

1. 발급받은 API Key, 오피스 도메인, 오피스 고유번호를 SSO 설정에 입력합니다.
2. **연결 테스트** 버튼으로 Temp Key 발급이 정상인지 확인합니다.

## SSO 설정 수정

- **수정** 버튼을 클릭하여 설정을 변경할 수 있습니다.
- API Key를 변경하지 않으려면 해당 필드를 **비워두고** 저장하면 기존 키가 유지됩니다.
- **활성/비활성** 토글로 SSO를 일시적으로 중단할 수 있습니다.

## SSO 사용 (일반 사용자)

1. 사이드바의 외부 서비스 링크를 클릭합니다.
2. 처음 사용 시 하이웍스 로그인 화면이 표시됩니다.
3. **하이웍스 아이디**(이메일 앞 아이디 부분만)를 입력하여 계정을 연동합니다.
4. 이후부터는 자동으로 하이웍스 서비스로 이동합니다.

> **참고**: 하이웍스 로그인 시 이메일 전체(user@domain.com)가 아닌 **아이디 부분만**(user) 입력해야 합니다.

## 공용 로그인 계정 운영 (선택)

기관 내 모든 Workhub 유저가 **하나의 하이웍스 계정**으로 공유 로그인하는 방식을 지원합니다. 외부 유저에게 개별 하이웍스 계정을 발급하기 어려운 경우에 유용합니다.

### 설정

1. SSO 설정에서 **공용 로그인 ID**에 공유할 하이웍스 아이디 입력 (예: `kjw`)
2. 저장 후 모든 Workhub 유저의 SSO 로그인이 이 계정으로 통합됨

### 동작 방식

- **공용 로그인 ID 미설정**: 유저별로 하이웍스 계정 매핑 (유저가 처음 접속 시 자격증명 입력 필요)
- **공용 로그인 ID 설정**: 모든 유저가 동일 계정으로 SSO → 하이웍스 관리자 페이지에 하나의 매핑만 생성됨

### 주의사항

- 공용 계정은 하이웍스 내에서 **활동 이력이 모두 동일 계정으로 기록**됩니다.
- 개별 감사(Audit)가 필요한 환경에서는 유저별 매핑 방식 권장.
