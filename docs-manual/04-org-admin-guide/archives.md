# 보관함

보관 또는 삭제된 프로젝트, 토픽, 채널을 관리합니다. 보관된 항목은 읽기 전용으로 조회할 수 있으며, 필요 시 복원하거나 영구 삭제할 수 있습니다.

## 보관함 접근

관리자 메뉴 > **보관함**으로 이동합니다.

## 보관된 항목 조회

보관함에서 다음 유형의 항목을 확인할 수 있습니다:

| 유형 | 설명 |
|------|------|
| 프로젝트 | 보관된 프로젝트와 하위 토픽 |
| 토픽 | 보관된 토픽 |
| 채널 | 보관된 채널 |

## 보관 상태

보관된 프로젝트/토픽/채널은 **읽기 전용** 상태입니다:
- 기존 메시지와 태스크를 조회할 수 있습니다.
- 새 메시지 작성, 태스크 생성/수정은 불가합니다.
- 구성원 변경, 설정 수정이 불가합니다.

## 복원

보관된 항목을 다시 활성 상태로 복원할 수 있습니다. 복원 시 모든 읽기/쓰기 기능이 다시 활성화됩니다.

## 영구 삭제

보관된 항목을 영구 삭제하면 복원할 수 없습니다. 삭제 전 영향받는 데이터(토픽 수, 태스크 수, 메시지 수)가 표시됩니다.
