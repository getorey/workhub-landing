# 명함을 내 핸드폰 연락처로 동기화

워크허브 CRM 에 등록된 외부 담당자(고객사 명함 등) 를 본인 스마트폰의
연락처 앱으로 자동 동기화하는 기능입니다.

> **단방향 · 본인 선택**:
> 회사가 직원 핸드폰에 일괄 푸시하는 게 아니라, 직원 본인이 명시적으로
> "내 연락처에 추가" 한 담당자만 본인 구글 계정을 거쳐 핸드폰에 등록됩니다.
> 동료가 본인 핸드폰에 추가한 것은 본인 핸드폰에 안 보입니다 — 각자 별도.

---

## 1. 동작 흐름

```
워크허브 CRM 담당자 목록 (회사 공유)
        │
        │ ① 본인이 체크 → "내 연락처에 추가" 클릭
        ▼
본인 구글 계정의 People API
        │
        │ ② "Workhub — 고객" 라벨 그룹 자동 부여
        ▼
구글 연락처 (contacts.google.com)
        │
        │ ③ 핸드폰의 구글 sync 가 자동으로 가져옴
        ▼
본인 스마트폰 연락처 앱
```

워크허브 → 구글: 즉시 (1~3초)
구글 → 핸드폰: 1~2분 (sync 주기)

---

## 2. 사전 준비 — 본인 구글 계정 연결 (한 번만)

> 이미 연결돼 있으면 3번 [동기화하기](#_3-동기화하기) 로 넘어가세요.

### 1) CRM → 담당자 페이지 진입

`/app/crm/contacts` 또는 좌측 사이드바 **고객관리 → 담당자** 탭.

### 2) 상단 배너의 "구글 계정 연결" 클릭

```
┌─────────────────────────────────────────────────────────────┐
│ 📱 내 구글 연락처와 연결하면 CRM 담당자를 본인 핸드폰 연락처에  │
│    추가할 수 있습니다.                       [구글 계정 연결]  │
└─────────────────────────────────────────────────────────────┘
```

### 3) 본인 Google 계정으로 로그인 + 권한 동의

Google 동의 화면에서:
- 본인이 사용 중인 Gmail 계정 선택
- 권한: **"연락처 보기 / 추가 / 수정"** 동의

> 회사가 관리하는 OAuth Client 를 통해 진행되지만, **권한은 본인 계정에만**
> 적용됩니다. 회사는 본인 구글 계정 자체에 접근하지 못합니다.

### 4) 연결 완료

배너가 초록색으로 바뀌면 준비 완료:

```
┌─────────────────────────────────────────────────────────────┐
│ ✓ 내 구글 연락처와 연결됨: you@example.com  · 추가된 0건      │
│                                                  [연결 해제] │
└─────────────────────────────────────────────────────────────┘
```

## 3. 동기화하기

### 1) 추가할 담당자 선택

담당자 목록 좌측의 **체크박스** 로 한 명 또는 여러 명 선택.

### 2) 상단 액션 바의 버튼 클릭

```
┌─────────────────────────────────────────────────────────────┐
│  2건 선택됨           [선택 해제]  [📱 내 연락처에 추가 (2)]   │
└─────────────────────────────────────────────────────────────┘
```

### 3) 성공 표시 확인

- 토스트: "2건 내 구글 연락처에 추가됨"
- 추가된 행의 "내 연락처" 열에 **🟢 연결됨** 배지 표시

### 4) 핸드폰에 도착 확인

- 보통 **1~2분 내** 본인 핸드폰 연락처 앱에 자동 표시
- 즉시 보고 싶으면 핸드폰 연락처 앱에서 새로고침 (잡아당기기)

## 4. iOS (아이폰) 설정

iOS 는 기본적으로 Google 연락처 sync 가 꺼져 있어 **최초 1회 설정** 이
필요합니다.

### 1) 설정 앱 → 연락처

iOS 의 **설정** 앱을 열고 **"연락처"** 메뉴 선택.

> iOS 버전에 따라 "메일" 안에 있을 수 있습니다.

### 2) "계정" → "계정 추가" → "Google" 선택

이미 Google 계정이 추가돼 있으면 → [그 계정 클릭 → 5번으로](#_5-iOS_-_연락처_토글_ON).

### 3) 워크허브에서 OAuth 동의한 그 Gmail 계정으로 로그인

> 이 단계에서 워크허브 연결과 동일한 Gmail 을 선택해야 합니다.
> 다른 계정을 추가하면 워크허브에서 push 한 연락처가 안 보입니다.

### 4) 동기화 항목 선택

- **연락처** 토글 → **ON** (필수)
- 메일 / 캘린더 / 메모는 본인 선택

### 5) 저장 후 1~2분 대기

핸드폰 **연락처** 앱을 열면 강건욱 등 워크허브에서 추가한 담당자가 표시됩니다.

### 그룹별 보기 (선택)

iOS 연락처 앱 좌상단 **"그룹"** 을 누르면:

- ✅ Gmail → **Workhub — 고객** (워크허브에서 추가한 담당자만)
- ✅ 다른 항목 모두 해제

→ 회사 명함과 개인 연락처가 깔끔히 분리되어 보입니다.

### 안 보일 때 점검

1. **설정 → 연락처 → 계정 → Gmail → "연락처" 토글이 켜져 있나?**
   - 꺼져 있으면 켜고 1~2분 기다림
2. **연락처 앱에서 위에서 아래로 잡아당겨 새로고침**
3. **그래도 안 보이면** — 설정에서 "연락처" 토글 OFF → ON
   (재동기화 강제)
4. **본인 Google 계정에는 등록됐는지** 먼저 확인:
   - 사파리에서 https://contacts.google.com 접속
   - 좌측 라벨 "**Workhub — 고객**" 그룹에 해당 담당자가 있어야 함

## 5. Android 설정

Android 는 보통 본인 Google 계정의 연락처 sync 가 **기본 활성**이라 별도 설정
불필요합니다. 워크허브에서 추가하면 1~2분 내 핸드폰에 표시됩니다.

### 만약 안 보이면

1. **설정** → **계정** (또는 "사용자 및 계정")
2. **Google** → 사용 중인 Gmail 계정 선택
3. **계정 동기화** → **연락처** 토글 ON
4. 우상단 메뉴 (⋮) → **"지금 동기화"** 누르기

### 그룹별 보기 (Pixel/삼성)

- Google 연락처 앱 (별도 설치): 좌상단 ☰ → "라벨" → **Workhub — 고객**
- 삼성 연락처 앱: 좌상단 ☰ → "라벨" 또는 "그룹" → **Workhub — 고객**

## 6. 자주 묻는 질문 (FAQ)

### Q. 동료가 내 핸드폰에 추가하면 내 연락처에도 보이나요?

**아니요.** 각 직원이 본인 핸드폰에 따로 추가해야 합니다.

- A 직원이 "내 연락처에 추가" → **A 핸드폰만** 등록
- B 직원이 같은 담당자를 본인 핸드폰에 받으려면 → **B 도 직접 체크 → 추가**

회사의 마스터 데이터(이름·전화·이메일)는 공유되지만, 핸드폰에 가져가는
건 각자의 선택입니다.

### Q. 회사가 내 핸드폰의 다른 연락처를 볼 수 있나요?

**볼 수 없습니다.**

- 동의한 권한은 **"내가 연락처를 추가/수정"** 만
- 본인이 직접 등록하지 않은 연락처는 워크허브가 읽을 수 없음
- "Workhub — 고객" 라벨 그룹의 항목만 워크허브가 추적

### Q. 담당자 정보가 워크허브에서 바뀌면 핸드폰에도 반영되나요?

지금은 **자동 갱신 안 됨**. 변경 후 다시 "내 연락처에 추가" 누르면 갱신됩니다.

> 향후 자동 갱신 기능을 검토 중입니다.

### Q. "연결 해제" 누르면 핸드폰 연락처도 지워지나요?

**아니요.**

- "연결 해제" = 워크허브 ↔ 본인 Google 계정의 **OAuth 토큰만 끊음**
- 본인 Google 연락처에 이미 등록된 사람은 그대로 보존
- 새로운 동기화만 중단

핸드폰에서 지우려면 Google 연락처 (https://contacts.google.com) 에서
"Workhub — 고객" 라벨 일괄 삭제.

### Q. 한 담당자를 핸드폰에서 빼고 싶으면?

워크허브 담당자 목록에서:
- 그 사람 행의 **✓ 연결됨** 배지 클릭 → 확인
- 본인 Google 연락처에서 삭제 + 핸드폰 sync 까지 1~2분 내 자동 반영

### Q. 퇴사하면 내 핸드폰 연락처는 어떻게 되나요?

- **본인 Google 계정의 연락처는 그대로 보존** (개인 자산)
- 워크허브 측 sync 만 중단 (OAuth 토큰 자동 회수)
- 핸드폰에 이미 있는 강건욱 등은 그대로 — 본인이 정리 원하면 위의
  "Workhub — 고객" 라벨 일괄 삭제

### Q. 다른 사람의 명함을 내 연락처에 추가한 게 회사에 보이나요?

회사 관리자에게 **누가 어떤 담당자를 본인 폰에 추가했는지** 는 보이지
않습니다 (audit 외부 노출 안 함). 본인 화면에서만 자기 sync 상태가 보입니다.

---

## 7. 보안 / 개인정보

- 권한 동의는 **본인 Google 계정** 기준 — 회사 관리자도 본인 권한을
  변경/회수할 수 없음
- 워크허브에 저장되는 정보: OAuth refresh token (AES-GCM 암호화),
  연결된 contact ID 매핑
- 본인이 언제든 https://myaccount.google.com/permissions 에서 워크허브
  권한 회수 가능 → 즉시 sync 중단
- 회수 후 다시 사용하려면 **사전 준비 2번** 부터 재진행
