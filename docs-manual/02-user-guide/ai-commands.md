# AI 슬래시 명령어

Workhub에서는 AI를 활용한 슬래시 명령어로 메시지 요약, 회의록 정리, 번역 등을 간편하게 처리할 수 있습니다.

---

## 시작하기

### AI 키 설정

AI 명령어를 사용하려면 먼저 개인 AI API 키를 설정해야 합니다.

1. 왼쪽 사이드바에서 **AI 설정**을 클릭합니다
2. **Gemini API 키**를 입력합니다
3. 모델을 선택합니다 (기본: `gemini-2.5-flash`)
4. **저장**을 클릭합니다

::: tip 무료 쿼터
Google Gemini는 무료 사용량을 제공합니다. AI 설정 페이지에서 현재 무료 쿼터 현황을 확인할 수 있습니다.
:::

---

## 사용 가능한 명령어

채널이나 토픽의 메시지 입력창에서 `/`를 입력하면 AI 명령어 목록이 표시됩니다.

### /요약 — 메시지 요약

최근 메시지를 AI가 요약하여 DM으로 전달합니다.

```
/요약          ← 최근 20개 메시지 요약
/요약 50       ← 최근 50개 메시지 요약
```

**결과 수신:** 봇이 DM으로 요약 결과를 보내줍니다.

### /회의록 — 회의록 정리

최근 대화를 회의록 형식으로 정리하여 DM으로 전달합니다.

```
/회의록        ← 최근 30개 메시지로 회의록 생성
/회의록 100    ← 최근 100개 메시지로 회의록 생성
```

**포함 내용:**
- 참석자
- 주요 논의 사항
- 결정 사항
- 액션 아이템

### /번역 — 텍스트 번역

입력한 텍스트를 번역합니다. 결과는 입력창 상단에 바로 표시됩니다.

```
/번역 Hello, how are you?        ← 한국어로 번역
/번역 en 안녕하세요               ← 영어로 번역
/번역 ja 오늘 회의 10시입니다     ← 일본어로 번역
```

**지원 언어:** 한국어, 영어(`en`), 일본어(`ja`), 중국어(`zh`) 등

### /도움말 — 명령어 안내

사용 가능한 모든 슬래시 명령어 목록을 확인합니다. 입력창 상단에 바로 표시됩니다.

```
/도움말
```

## AI 명령어 사용 팁

### 결과 수신 방식

| 명령어 | 결과 위치 |
|--------|----------|
| `/요약`, `/회의록` | **DM**으로 전달 (봇 DM 확인) |
| `/번역`, `/도움말` | **입력창 상단**에 바로 표시 |

### 토픽에서 사용하기

프로젝트 토픽에서 AI 명령어를 사용하면, **해당 토픽의 메시지**만 대상으로 처리됩니다. 예를 들어 디자인 토픽에서 `/요약`을 실행하면 디자인 관련 대화만 요약합니다.

::: warning 주의사항
- AI API 키가 설정되지 않으면 명령어 실행 시 안내 메시지가 표시됩니다
- 요약/회의록은 처리에 수 초가 걸릴 수 있습니다
- 결과는 본인에게만 DM으로 전달되며, 다른 사람에게는 보이지 않습니다
:::
