# 사용자 가이드

일반 사용자를 위한 기능 가이드입니다.

## 목차

1. [프로젝트](./projects.md) — 프로젝트 생성, 참여, 토픽 관리
2. [메시지](./messaging.md) — 채널/토픽 메시징, 쓰레드, 리액션, 멘션
3. [태스크](./tasks.md) — 칸반 보드, 간트 차트, 태스크 관리
4. [다이렉트 메시지](./dm.md) — 1:1 DM, 그룹 DM
5. [채널](./channels.md) — 채널 가입, 메시지, 설정
6. [연락처](./contacts.md) — 연락처 관리, 그룹, 차단
7. [조직도](./org-tree.md) — 조직 구조 조회, 구성원 검색
8. [검색](./search.md) — 통합 검색
9. [파일](./files.md) — 파일 업로드, 다운로드
10. [봇 사용법](./bots.md) — 스탠드업, 태스크 알림, 투표/설문, 취합 봇

## 계정 관리

**내 프로필** 페이지에서 다음을 관리할 수 있습니다:

- 표시 이름 / 아바타 / 소속 부서 편집
- **계정 탈퇴** (페이지 하단 "위험 영역"):
  - 현재 비밀번호 + "탈퇴" 문구를 입력하면 즉시 로그아웃되고 계정이 탈퇴 상태로 전환됩니다.
  - 작성한 메시지·태스크 등은 그대로 보존됩니다.
  - 동일 이메일로 재가입 시 이전 계정이 자동 복구됩니다.

> SSO(Hiworks/Zitadel)로만 로그인하는 계정은 본인 탈퇴 경로를 사용할 수 없습니다. 기관 관리자에게 요청하세요.
