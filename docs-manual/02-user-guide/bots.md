# 봇 사용 가이드

Workhub에는 업무 자동화를 도와주는 **4가지 봇**이 내장되어 있습니다. 봇은 채널에서 슬래시 명령어(`/`)로 실행하거나, DM을 통해 자동으로 알림을 받을 수 있습니다.

---

## 봇 시작하기

봇을 처음 사용하는 분을 위한 기본 안내입니다.

### 봇이란?

봇은 채널이나 DM에서 자동으로 동작하는 **자동화 도우미**입니다. 사람처럼 메시지를 보내고 받지만, 정해진 규칙에 따라 자동으로 동작합니다.

봇은 세 가지 방식으로 동작합니다:

| 유형 | 설명 | 예시 |
|------|------|------|
| **자동 봇** | 정해진 시간에 알아서 DM을 보냅니다 | 스탠드업 봇, 태스크 알림 봇 |
| **명령어 봇** | 사용자가 채널에서 `/명령어`를 입력하면 동작합니다 | 투표/설문 봇, 취합 봇 |
| **@멘션 봇** | `@봇이름 질문`으로 직접 대화합니다 | 검색 봇, 알림 봇 |

### 봇 메시지 구분하기

채널이나 DM에서 봇이 보낸 메시지는 일반 사용자 메시지와 구분됩니다:

- 프로필 이름 옆에 **`봇`** 배지가 표시됩니다
- 봇 메시지는 자동화된 형식(표, 리스트 등)으로 정리되어 있습니다

### 채널에서 슬래시 명령어 사용하기

투표, 설문, 취합 등의 봇은 **슬래시 명령어**로 실행합니다.

**사용 방법:**

1. 봇이 활성화된 **채널**에 들어갑니다
2. 하단 메시지 입력창에 `/`를 입력합니다
3. 사용 가능한 명령어 **자동완성 목록**이 나타납니다
4. 원하는 명령어를 선택하거나 직접 입력합니다
5. 명령어 뒤에 필요한 내용을 작성하고 **Enter**를 누릅니다

```
예시: /투표 점심 메뉴 | 한식 | 중식 | 양식
```

::: tip 자동완성 활용
`/`를 입력하면 현재 채널에서 사용할 수 있는 모든 명령어가 표시됩니다. 명령어 이름 일부를 추가로 입력하면 목록이 필터링됩니다.
:::

### 봇 DM 확인하기

자동 봇(스탠드업, 태스크 알림)이나 설문/취합 봇은 **DM(다이렉트 메시지)**으로 질문을 보냅니다.

**DM 확인 방법:**

1. 왼쪽 사이드바에서 **DM** 메뉴를 클릭합니다
2. DM 목록에서 **봇 이름**(예: "스탠드업 봇", "취합 봇")을 찾습니다
3. 읽지 않은 메시지가 있으면 **알림 뱃지**가 표시됩니다
4. 봇 대화방을 클릭하여 내용을 확인합니다

### 봇에게 답변하기

봇이 DM으로 질문을 보내면, **같은 DM 대화방에서 텍스트를 입력**하면 됩니다.

::: warning 주의
- 봇이 보낸 **DM 대화방 안에서** 답변해야 합니다 (다른 채널에서 답변하면 인식하지 못합니다)
- **텍스트만** 인식합니다 — 이미지나 파일 첨부는 답변으로 인식되지 않습니다
:::

## 데일리 스탠드업 봇

매일 아침 담당 태스크 목록을 보여주고, **단답형 명령어**로 태스크 상태를 바로 업데이트할 수 있습니다.

### 동작 흐름

```
09:00  담당 태스크 목록 + 명령어 안내 DM 발송
       ↓ 단답형 명령으로 태스크 업데이트
09:30  미응답자에게 리마인더 발송
10:00  채널에 스탠드업 리포트 게시
```

### 받게 되는 메시지

봇이 DM으로 담당 태스크 목록을 **프로젝트 > 토픽** 계층으로 보여줍니다:

```
🌅 좋은 아침입니다, Kim님!

📋 담당 태스크 3건:
  📁 워크허브 > 프론트엔드
    🔵 1. 로그인 페이지 리디자인 [긴급] (D-1)
    ⬜ 2. 대시보드 차트 컴포넌트 [보통] (D-5)
  📁 워크허브 > 백엔드
    🔵 3. API 리팩토링 [낮음] (D-10)

──────────────
태스크 상태를 업데이트해 주세요:
  완료 → "1완료"  진행 → "2진행"
  블록 → "3블록 사유"  연장 → "1연장"
  여러개 → "1완료 2진행"
  건너뛰기 → "다음"
```

### 단답형 명령어

| 명령어 | 동작 | 예시 |
|--------|------|------|
| `N완료` | 태스크를 **완료** 처리 | `1완료` |
| `N진행` | 태스크를 **진행 중** 상태로 변경 | `2진행` |
| `N블록 사유` | 태스크를 **블로커** 상태로 변경 + 사유 기록 | `3블록 API 미확정` |
| `N연장` | 마감일을 **+3일** 연장 | `1연장` |
| `다음` | 태스크 업데이트를 건너뛰기 | `다음` |

::: tip 여러 태스크 한 번에 처리
공백으로 구분하여 한 줄로 여러 태스크를 처리할 수 있습니다:
```
1완료 2진행 3블록 API스펙 미확정
```
:::

### 새 태스크 생성

태스크 업데이트 후 오늘 할 새 업무를 등록할 수 있습니다:

```
봇: 오늘 새로 할 일이 있나요?
    "생성 태스크제목" 또는 "없음"

나: 생성 사용자 프로필 페이지

봇: 📁 어디에 생성할까요?
      1. 워크허브 > 프론트엔드
      2. 워크허브 > 백엔드

나: 1

봇: ✅ "사용자 프로필 페이지" 생성 완료!
```

### 스탠드업 리포트

10:00에 채널에 자동으로 게시되는 리포트에는 다음이 포함됩니다:

- 각 팀원의 태스크 업데이트 내역 (완료/진행/블로커)
- 새로 생성한 태스크 목록
- 블로커가 있는 경우 별도 표시
- 응답률 통계

::: tip
담당 태스크가 없으면 바로 새 태스크 생성 단계로 넘어갑니다.
:::

## 태스크 알림 봇

퇴근 전에 마감 임박/초과 태스크를 **프로젝트 > 토픽** 계층으로 정리하여 DM으로 보내줍니다. 번호를 선택하여 개별 태스크를 처리할 수 있습니다.

### 동작 흐름

```
17:00  마감 임박/초과 태스크 스캔 → 담당자에게 DM 알림
       ↓ 번호 선택 → 상태 업데이트
17:30  채널에 일일 태스크 리포트 게시
```

### 알림 시점

| 시점 | 알림 내용 |
|------|----------|
| **D-3** | 마감 3일 전 — 사전 알림 |
| **D-1** | 마감 1일 전 — 긴급 알림 |
| **D-Day** | 마감일 당일 |
| **D+1** | 마감 1일 초과 — 지연 경고 |
| **D+3** | 마감 3일 초과 — 에스컬레이션 |

### DM 알림 예시

```
🔔 태스크 마감 알림 — 3건

📁 워크허브 > 프론트엔드
  🚨 1. 로그인 리디자인 [긴급] (마감: 04-08, 2일 초과)
  🔥 2. 대시보드 차트 [보통] (마감: 04-10, D-Day)

📁 워크허브 > 백엔드
  🔔 3. API 리팩토링 [낮음] (마감: 04-13, D-3)

──────────────
번호를 입력하여 태스크를 선택하세요 (예: 1)
"전체완료" — 모든 태스크를 완료 처리
"0" — 종료
```

### 답변 방법

**Step 1 — 태스크 선택:**

번호를 입력하면 해당 태스크의 상세 정보와 액션 메뉴가 표시됩니다.

```
나: 1

봇: 🚨 로그인 리디자인 [긴급]
    📁 워크허브 > 프론트엔드 | 📅 04-08 (D+2)

    1️⃣ 완료했어요 → "done"으로 변경
    2️⃣ 진행 중이에요 → 상태 유지
    3️⃣ 마감 연장 필요 → 연장 요청
    0️⃣ 돌아가기
```

**Step 2 — 액션 선택:**

| 답변 | 동작 |
|------|------|
| **1** | 태스크를 "완료"로 변경 (완료일 자동 기록) |
| **2** | "진행 중" 상태 유지 |
| **3** | 마감 +3일 연장 (사유 입력 → 관리자 보고) |
| **0** | 목록으로 돌아가기 |

**처리 후:** 남은 태스크가 있으면 재번호가 부여된 목록이 다시 표시됩니다. 모든 태스크를 처리하면 세션이 종료됩니다.

::: tip 전체완료
태스크가 모두 끝났다면 `전체완료`를 입력하여 한 번에 모두 완료 처리할 수 있습니다.
:::

### 일일 태스크 리포트

매일 17:30에 지정된 채널에 자동으로 리포트가 게시됩니다:

- 마감 초과 태스크 목록 (프로젝트 > 토픽 표시)
- 오늘 마감 태스크 목록
- 마감 임박 태스크 목록
- 각 담당자별 현황

::: warning
태스크에 마감일을 설정해야 알림을 받을 수 있습니다. 칸반 보드에서 태스크를 편집하여 마감일을 지정하세요.
:::

## 투표/설문 봇

채널에서 실시간 투표를 진행하거나, DM 기반의 설문조사를 실행할 수 있습니다.

### 투표 만들기

채널 메시지 입력창에서 슬래시 명령어를 입력합니다:

```
/투표 제목 | 항목1 | 항목2 | 항목3
```

#### 옵션

| 옵션 | 설명 | 예시 |
|------|------|------|
| `--익명` | 익명 투표 (누가 투표했는지 비공개) | `/투표 점심 메뉴 | 한식 | 중식 --익명` |
| `--복수` | 복수 선택 허용 | `/투표 회식 날짜 | 월 | 화 | 수 --복수` |
| `--시간 30분` | 제한 시간 설정 (기본: 60분) | `/투표 긴급 안건 | 찬성 | 반대 --시간 10분` |

#### 예시

```
/투표 이번 주 회식 장소 | 고깃집 | 횟집 | 이탈리안 | 중식당 --복수 --시간 120분
```

### 투표 참여 방법

1. 봇이 채널에 투표 카드를 게시합니다
2. **번호를 입력**하여 투표합니다 (예: `1`, `2`, `3`)
3. 복수 선택이 허용된 경우 쉼표로 구분합니다 (예: `1,3`)
4. 5표마다 중간 결과가 자동으로 표시됩니다
5. 제한 시간이 지나면 최종 결과가 게시됩니다

### 설문조사 만들기

DM 기반의 다중 질문 설문을 실행합니다:

```
/설문 분기 만족도 조사
```

#### 옵션

| 옵션 | 설명 |
|------|------|
| `--익명` | 익명 설문 |

### 설문 참여 방법

1. `/설문` 명령을 실행하면 채널 구성원에게 DM이 발송됩니다
2. 봇 DM에서 질문에 하나씩 답변합니다
3. 텍스트 답변 또는 점수(1~5) 평가를 합니다
4. 모든 응답이 수집되면 채널에 결과 리포트가 게시됩니다

### 설문 결과 리포트

- 텍스트 응답: 주요 키워드 분석
- 점수 응답: 평균 점수 계산
- 응답률 표시

## 취합 봇

팀원들에게 DM으로 자료나 의견을 요청하고, 마감일에 자동으로 결과를 모아 채널에 게시합니다.

### 취합 요청 만들기

```
/취합 제목 | 마감: 날짜 | 항목: 항목1, 항목2
```

#### 예시

```
/취합 주간 업무 보고 | 마감: 2026-04-11 | 항목: 이번주 성과, 다음주 계획, 이슈사항(선택)
```

- **제목**: 취합 주제
- **마감**: 마감일 (YYYY-MM-DD 형식)
- **항목**: 수집할 항목 목록 (쉼표 구분)
- 항목 뒤에 `(선택)`을 붙이면 선택 항목이 됩니다

### 응답 방법

1. 봇이 채널 구성원에게 DM으로 취합 요청을 보냅니다
2. 각 항목에 대해 **순서대로 텍스트로 답변**합니다
3. 답변 완료 전에 **검토 및 수정**할 수 있습니다
4. 최종 제출 후 요청자에게 알림이 갑니다

### 진행 상황 확인

취합을 요청한 사람은 진행 상황을 확인할 수 있습니다:

```
/취합현황
```

- 응답 완료/미응답 인원 확인
- 실시간 응답률 표시

### 리마인더

- 매일 오전 9시에 미제출자에게 자동으로 리마인더가 발송됩니다
- 마감일에 자동으로 결과 보고서가 채널에 게시됩니다

### 결과 보고서

마감 시 채널에 자동으로 게시되는 보고서에 포함되는 내용:

- 응답률 (제출/전체)
- 각 팀원의 항목별 응답 내용
- 미응답자 목록

::: tip
선택 항목은 응답하지 않아도 제출이 가능합니다. 필수 항목은 반드시 답변해야 합니다.
:::

## @멘션으로 봇 호출하기

슬래시 명령어 외에도 `@봇이름`으로 봇을 호출할 수 있습니다. 채널, 프로젝트 토픽, DM 어디에서든 사용 가능합니다.

### 사용 방법

1. 메시지 입력창에서 `@`를 입력합니다
2. 멘션 목록에서 **봇** 섹션의 봇을 선택합니다
3. 봇 이름 뒤에 질문이나 요청 내용을 작성합니다
4. Enter를 누르면 봇이 쓰레드(답글)로 응답합니다

```
@검색봇 이번 달 회의록 찾아줘
@알림봇 내 마감 임박 태스크 알려줘
```

::: tip
멘션 목록은 **사람**, **조직**, **봇** 세 그룹으로 구분되어 표시됩니다. 봇은 이름 옆에 **봇** 배지가 붙어 있어 쉽게 구분할 수 있습니다.
:::

## 슬래시 명령어 요약

| 명령어 | 봇 | 설명 |
|--------|-----|------|
| `/요약` | AI 봇 | 최근 메시지 요약 (DM 전달) |
| `/회의록` | AI 봇 | 회의록 정리 (DM 전달) |
| `/번역 텍스트` | AI 봇 | 텍스트 번역 |
| `/도움말` | 시스템 | 명령어 목록 안내 |
| `/투표 제목 \| 항목1 \| 항목2` | 투표/설문 봇 | 채널 투표 생성 |
| `/설문 제목` | 투표/설문 봇 | DM 설문조사 생성 |
| `/취합 제목 \| 마감: 날짜 \| 항목: ...` | 취합 봇 | 자료 취합 요청 |
| `/취합현황` | 취합 봇 | 취합 진행 상황 확인 |

::: info
슬래시 명령어는 채널 메시지 입력창에서 `/`를 입력하면 자동완성 목록이 표시됩니다.
AI 명령어에 대한 자세한 내용은 [AI 슬래시 명령어](/02-user-guide/ai-commands) 페이지를 참고하세요.
:::

## 봇에게 답변하는 팁

1. **DM에서 답변** — 봇이 보낸 DM 대화방에서 바로 텍스트를 입력하면 됩니다
2. **단답형 명령** — 스탠드업 봇은 `1완료 2진행` 같은 단답형 명령을 사용합니다
3. **번호 선택** — 태스크 알림 봇은 번호로 태스크를 선택하고 액션을 고릅니다
4. **한 줄 일괄 처리** — 스탠드업에서 여러 태스크를 한 줄로 처리할 수 있습니다

::: warning 주의사항
- 봇은 **텍스트 메시지만** 인식합니다 (이미지, 파일은 인식하지 않음)
- 봇의 응답 데이터는 메모리에 저장되므로, **서버 재시작 시 진행 중인 세션이 초기화**될 수 있습니다
- 봇 관련 문제가 발생하면 기관관리자에게 문의하세요
:::
