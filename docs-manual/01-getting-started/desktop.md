# 데스크톱 앱

Workhub 데스크톱 앱은 Windows용 네이티브 클라이언트입니다.
웹 브라우저 없이도 Workhub를 사용할 수 있으며, **시스템 트레이 상주**와 **실시간 알림**을 지원합니다.

## 주요 기능

| 기능 | 설명 |
|------|------|
| 시스템 트레이 상주 | 앱을 닫아도 트레이에서 계속 실행 |
| Windows 토스트 알림 | 새 메시지, 멘션, 태스크 알림을 실시간 수신 |
| 자동 시작 | Windows 시작 시 자동 실행 (설정 가능) |
| 경량 실행 | 메모리 50~100MB, 설치 파일 약 10MB |

## 설치

1. 관리자로부터 전달받은 설치 파일(`WorkHub_x.x.x_x64-setup.exe`)을 실행합니다.
2. 설치 마법사의 안내에 따라 진행합니다.
3. 설치 완료 후 Workhub가 자동으로 실행됩니다.

::: tip
설치 시 Windows SmartScreen 경고가 표시될 수 있습니다.
"추가 정보" → "실행"을 클릭하여 진행하세요.
(코드 서명이 적용된 버전에서는 이 경고가 표시되지 않습니다.)
:::

## 사용법

### 로그인

데스크톱 앱의 로그인 방법은 웹 버전과 동일합니다.
서버 URL이 사전 설정되어 있으므로 계정 정보만 입력하면 됩니다.

### 시스템 트레이

데스크톱 앱은 창을 닫아도 종료되지 않고 **시스템 트레이(작업 표시줄 알림 영역)**에 상주합니다.

- **트레이 아이콘 클릭** → 앱 창 열기
- **트레이 아이콘 우클릭** → 메뉴 표시
  - **WorkHub 열기** — 앱 창을 전면으로 표시
  - **숨기기** — 앱 창을 숨기고 트레이에만 상주
  - **종료** — 앱 완전 종료

### 실시간 알림

로그인 상태에서는 SSE(Server-Sent Events)를 통해 서버의 알림을 실시간으로 수신합니다.

- 앱이 **숨김 상태이거나 비활성** 상태일 때 Windows 토스트 알림이 표시됩니다.
- 앱이 **활성 상태**일 때는 앱 내 알림만 표시됩니다 (토스트 알림 없음).
- 알림을 클릭하면 해당 채널, DM, 또는 태스크로 바로 이동합니다.

### 웹 버전과의 차이

데스크톱 앱의 기능은 웹 버전과 **동일**합니다. 추가적으로 다음을 지원합니다:

- 시스템 트레이 상주 (백그라운드 실행)
- Windows 네이티브 토스트 알림
- OS 시작 시 자동 실행

::: info
채널, 메시지, 프로젝트, 태스크 등 모든 기능은 웹과 동일하게 동작합니다.
웹에서 작업한 내용은 데스크톱에서도 그대로 확인할 수 있습니다.
:::
